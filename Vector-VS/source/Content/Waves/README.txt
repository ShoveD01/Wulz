VECTOR VS - ROM WAVES (wave numbers 32-127)
-------------------------------------------
Vector VS ships with its own ORIGINAL bank of 96 generated waves (eight morphing families of twelve: pulse/PWM, brightness, hollow,
vowels, bells and metals, organs, FM, digital oddities), so it works with nothing in this folder.

If you own the three 44.1 kHz float WAV files of the original instrument's ROM waves, put them here with exactly these names:

    PROPHET_VS1.WAV   (33 slots of 2048 samples: waves 32-64)
    PROPHET_VS2.WAV   (slots 2-32:               waves 65-95)
    PROPHET_VS3.WAV   (slots 1-32:               waves 96-127)

Each file you add replaces its own third of the bank; a missing file keeps the generated waves for that third. Restart the MPC after changing files.
The wave pictures on the touch screen always show the generated waves. The sound always uses the files if they are present.
These files are not included with Vector VS and are not covered by its licence.
