# Wulz
My MPC Pluginz. Plugins for **Akai MPC standalone** hardware, by wul. Each plugin has its own folder with downloads, install instructions and pictures.

| Plugin | What it is |
|---|---|
| [Vector VS](Vector-VS/) | 8-voice, 4-oscillator vector synth (Prophet VS style): vector pad with movement recorder, 24 dB ladder filter, 5-stage envelopes, 2 LFOs + mod matrix, ensemble chorus, 120 presets, randomize. |
| [ZeroCoast](ZeroCoast/) | West-Coast semi-modular voice: triangle VCO, overtone, wavefolder, slope + contour generators, vactrol low pass gate, patch matrix, clock / LFO / stepped random, quantized randomizer, 120 presets. |

All MPC plugins need **MPC OS 3.10.1 or later** and **External Plugin Support** turned on (see each plugin's page).
